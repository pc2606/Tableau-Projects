# Sales Performance Dashboard – Tableau

## Project Overview
This project is an interactive Sales Performance Dashboard created using Tableau.
The dashboard helps analyze sales performance and understand important business insights through data visualization.

## Tools & Technologies
- Tableau
- Data Visualization
- Excel / CSV Dataset

## Dashboard Features
- Sales Performance Analysis
- Category-wise Sales Analysis
- Regional Sales Analysis
- Profit Analysis
- Interactive Filters
- Charts and Visualizations
- KPI-based analysis

## Charts Used
- Bar Chart
- Line Chart
- Pie Chart
- Map
- KPI Cards
- Filters

## Key Insights
- Analyzed overall sales and profit performance.
- Compared sales across different categories and regions.
- Identified trends and patterns using interactive visualizations.
- Used filters to explore the data dynamically.
